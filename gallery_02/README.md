# Wildflowers 🌼

#### Wildflowers is a botanical image gallery created as part of my front-end web development practice projects.

#### The project explores CSS Grid, Flexbox, image composition, and custom page layouts through a collection of wildflower photographs arranged in circular frames.

## Project Overview

The gallery features a large central image surrounded by smaller circular thumbnails. The design focuses on visual balance, spacing, alignment, and creating a cohesive composition within the browser viewport.

## Technologies

- HTML5

- CSS3

- JavaScript (planned)

## Current Features

- Circular botanical image gallery

- Large central featured image

- Smaller circular thumbnail images

- CSS Grid-based gallery layout

- Flexbox-based page structure

- Separate CSS files for individual components
